## Why

Windows users need an installer that behaves like a native application (Start menu
entry, uninstall, icon, no console window, signed binary) — the old `gui-windows` crate
was an empty stub.

## What Changes

- Release builds use the Windows GUI subsystem (no console window) — implemented.
- Multi-resolution `summrise.ico` generated by `cargo xtask icons` — implemented.
- Embed icon and version information into `summrise.exe` (`winresource` build script).
- Per-user MSI installer (WiX 4 or `cargo-packager`) with Start-menu shortcut and
  uninstaller; keep the portable zip.
- Authenticode signing in CI when a certificate is configured.
- Verify removable-media detection on drive letters and settings in `%APPDATA%`.

## Capabilities

### New Capabilities
- `windows-packaging`: building, signing and installing SumMRIse on Windows.
